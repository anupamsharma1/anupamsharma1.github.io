How this system is built

Data Model

The taxonomy, dimensions and tables every screen above reads from. Because all screens compute live from the same two fact tables, no two screens can disagree.

Investment Tree

Every rupee lands on exactly one leaf — including team costs and offline spend

Return Tree

Every outcome lands on exactly one leaf — including the slow returns

Shared Dimensions

Investment and return carry the identical dimension set, captured at entry — this is what makes every comparison on every screen possible

Tables & Relationships

Two fact tables, nine dimension tables, one audit log. Nothing is pre-aggregated and stored twice.
